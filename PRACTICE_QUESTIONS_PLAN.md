# Practice Questions Plan — All 46 Topics

Each topic gets **10 open-ended practice questions** (no multiple-choice).
Each question shows only the prompt; a "Show Answer" button reveals the full worked solution.
Questions are sourced from MEXT exam papers in the `examples/` folder or closely adapted from them.

## Question Format

Questions are stored in the `practiceQuestions` array inside each `src/content/topics/tNN.json` file:

```json
"practiceQuestions": [
  {
    "id": "t01-p01",
    "source": "2019-UG-Q1-(1) adapted",
    "question": "Question text with $LaTeX$ math...",
    "answer": "Full worked answer with $LaTeX$ math..."
  }
]
```

Rendered in the topic page as a "Practice Questions" section with a **Show Answer** toggle per question (no choices shown).
